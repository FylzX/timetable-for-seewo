# 桌面课表

一个适用于 Windows 的桌面课表工具，自动显示当天课程，突出显示正在上课或即将开始的课程，支持日常排课、临时调课和节假日安排

使用 C#、.NET 8 和 WinUI 3 开发，支持 Windows 10 1809 及以上的 x64 系统，推荐 Windows 11

## 启动

打开便携版文件夹，双击 `DesktopTimetable.exe`，无需安装额外运行环境

课表保持在桌面层，不遮挡其他窗口，按 Win+D 后仍然可见

迁移到其他电脑时，复制整个文件夹即可，保留其中的 `app/`、课表文件和 `user-data/`，课程安排与窗口设置会一起带走

## 日常使用

右上角从左到右是 GitHub、编辑和锁定按钮

- 点击 GitHub 图标打开[项目仓库](https://github.com/FylzX/timetable-for-seewo)
- 点击铅笔打开课表编辑器
- 点击锁解锁窗口，随后可以拖动位置、拖动边缘调整大小，再次点击即可锁定

右键课表或托盘图标，可以预览其他星期的课表、调整测试时间、检查更新、恢复默认位置或退出程序

选择“检查更新”会显示本机和 GitHub 最新正式版本，没有新版时会提示已是最新版；有新版时可查看更新说明，确认后下载并自动更新、重启

更新会保留课表和窗口设置，失败时尝试恢复旧程序

## 编辑课表

### 主课表

周一至周五各占一列，每天都可以独立添加课程，课程时间可以自由设置

点击课程卡片的名称、时间或空白处，可以在同一个窗口修改课程和时间，时间支持文字输入和滚轮选择，悬停时点击红色垃圾桶即可删除

空白列的“添加课程”按钮位于中央，有课程时位于列底部，各列相同时间横向对齐，内容较多时可以滚动或使用上下箭头查看

### 例外日期

用于临时调课和假期安排，添加日期时可以复制主课表中的某一天，每个日期都能独立添加课程或删除整天安排

例外日期的课表会替换当天的主课表，空白例外日期表示当天放假，删除该日期后恢复使用主课表

### 时间模板

左侧面板用于设置共用的上课时间，可以随时收起或展开

模板可以应用到所有工作日、某个工作日或某个例外日期，之后再填写课程名称，目标已有内容时会先确认是否整列覆盖

改完后点击“保存课表”，桌面会立即更新；时间重叠时会提醒，确认后仍可保留，课程名称未填完整时会提示修正，未保存就关闭窗口时可以选择保存、放弃或继续编辑

## 测试时间

右键选择“调整测试时间”，选择日期和时间，或直接拖动钟表上的时针和分针，即可查看不同时间下的课表状态

模拟时间不会修改电脑的系统时钟，关闭测试窗口后仍会继续运行，点击“恢复电脑时间”或重启程序即可恢复正常

## 课表文件

数据保存在启动入口旁边，可以通过编辑器修改，也可以自行备份

| 文件 | 用途 |
| --- | --- |
| `timetable.json` | 主课表 |
| `exceptions.json` | 例外日期 |
| `template.json` | 共用时间模板 |
| `user-data/` | 窗口设置和运行日志 |

缺失的 JSON 文件会自动生成，已有文件不会被覆盖，模板缺失时会尝试从现有课表提取时间

启动异常时可查看 `user-data/startup.log`

## 从源码构建

需要 .NET 8 SDK，首次构建会从 NuGet 下载依赖

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./build-portable.ps1
```

完成后双击 `release/DesktopTimetable.exe`，重新构建会保留该目录中已有的课表和窗口设置

也可以双击 `view-csharp.cmd` 直接从源码运行
