此目录是保留的 Python 旧版，包含独立的课表快照。以下为迁移前的说明，文中的源码与 Python 打包命令在此目录执行；新版 C# 说明见仓库根目录 README.md。

# 桌面课表

Python 3.10+，Windows 10 / 11
储在外置 `timetable.json` 中，运行及打包后不依赖 PDF，也不内置课表。

## 外置课表与特殊日期

源码运行时读取 `app.py` 同目录的 `timetable.json` 和 `exceptions.json`；打包后读取 EXE 同目录的这两个文件，与启动时的工作目录无关。编辑器保存后立即生效；手动修改 JSON 后需重新启动程序，无需重新打包。

## 可视化编辑课表

点击主面板右上角锁按钮旁的铅笔按钮，或右键选择“编辑课表”。编辑器是 C# / WinUI 3 原生独立窗口，使用系统主题、原生下拉框、时间选择器和确认弹窗，提供“主课表”和“例外日期”两个选项卡。Windows 11 支持 Mica 背景。主面板的编辑和锁定按钮均有白色圆角背景，锁定不影响编辑课表。

源码开发需要 .NET 8 SDK。先在根目录手动执行 `dotnet build winui-editor/Timetable.Editor.csproj`，再运行 Python 主程序；也可直接执行 `./winui-editor/run-editor.ps1` 单独查看编辑器。这里只进行开发构建，正式分发目标为自包含 portable 文件夹，无需目标电脑安装运行环境或使用 Program Files。此阶段桌面课表和时间测试仍由 Python 提供，尚未形成统一 C# 的完整分发版本。详细说明见 [WinUI 编辑器说明](winui-editor/README.md)。

需要手动生成便携文件夹时，在开发环境运行 `./build-portable.ps1`。脚本会生成 `release/DesktopTimetable.exe`、三个 JSON 文件和 `release/editor/` 自包含 WinUI 运行目录；不会安装依赖、写入系统目录或生成安装包。整个 `release` 文件夹可以直接复制或压缩移动，并已加入 Git 忽略。

- 主课表使用共享时间轴显示周一至周五，相同时间横向对齐，整天课程适配窗口高度，无独立列滚动。无课长空档压缩，卡片高度不代表精确时长。每一天底部有轻量“＋ 添加课程”操作，可自定义课程时间；点击时间可独立修改，点击课程卡片的任意空白区域或课程名称均可打开选择菜单。“自定义课程…”在弹窗提供输入框。卡片右侧的红色垃圾桶在悬停或键盘聚焦时显示并贯穿卡片高度；时间轴旁有操作提示。
- 共享模板默认在左侧展开为独立纵列，点击标题旁箭头可收起到左侧竖向入口；可添加、修改、删除时间段，通过一个应用范围下拉菜单选择所有工作日或一个工作日，再点击“应用模板”。例外日期页使用同一份模板，只应用到选中的已创建日期。修改模板不会自动更改已经安排的课程。
- 目标日期已有课程时，先确认“覆盖当前内容”；确认后清空目标日期，并按模板创建等待选择课程的空卡片，取消不作任何更改。应用到所有工作日的确认覆盖整个操作。
- “添加日期”可选择空白课表或复制周一至周五之一，新日期列追加到最右侧。例外日期使用与主课表相同的列宽，日期超过可视范围时左右滚动；点击日期标题选中整列，底部只有一个针对当前日期的“＋ 添加课程”。删除整个日期需要确认。空日期表示当天放假，删除日期则恢复使用主课表。
- 例外日期列之间有额外间隔和竖向分割线；共享时间轴按课程数量和最小可读卡片高度计算内容高度，只有内容确实超过视口时才出现上下滚动。右上角和右下角的上下箭头按视口步长滚动，右侧滚动条仍可拖动，也支持横向拖动选择日期。主课表使用相同的动态高度和滚动方式。
- 右上角“保存课表”同时保存两个课表和共享模板，并立即刷新桌面。保存前会校验所有主课表、例外日期和模板：时间格式错误、时间重叠、结束早于开始、课程未填写都会阻止写盘，校验失败时原文件保持不变。未保存时点击 X 或关闭，窗口内容会摇动，随后提供“保存并关闭 / 放弃修改 / 继续编辑”。退出主程序也会先处理未保存的编辑。编辑期间文件被其他程序修改时，会先确认是否覆盖。

共享模板保存为程序目录的 `template.json`，首次打开且此文件不存在时，从已有周四课表（或首个非空星期）提取时间段；只有保存编辑时才写入。迁移电脑时可同时携带三个 JSON。课表仍由外置文件提供；内嵌数据、自动生成缺失课表和数据同步方案暂未加入。

## 测试日期与时间

右键主课表或托盘选择“调整测试时间”。默认同步电脑时间；可以拖动时针或分针，也可输入日期和 `HH:mm:ss`，点击“启用测试时间”后桌面显示“测试时间”，日期、课程和实时高亮均随模拟时间更新，模拟时间按秒继续走。点击“恢复电脑时间”立即回到系统时间；关闭测试窗口不会停止模拟，退出并重启程序后恢复系统时间。此功能不修改 Windows 系统时钟。

`timetable.json` 的键为 `"1"` 至 `"7"`（周一至周日），值为当天完整课程数组，每条课程使用 `start`、`end`、`course`：

```json
{
  "1": [{"start": "08:00", "end": "08:40", "course": "语文"}],
  "7": []
}
```

`exceptions.json` 使用 `YYYY-MM-DD` 日期作为键，值为该日期的完整课程数组，优先级高于常规周课表，整天替换而非合并。空数组表示当天放假；没有特例的日期使用常规周课表。没有任何特例时保留文件，内容写为 `{}`。

已录入 `2026-09-20` 的特例，内容为当前周四的全部 12 条课程。该日标题仍显示星期日，但课程及当前/下一节高亮均按此特例计算。这是一份独立副本，后续修改常规周四课程不会自动改变此特例。

两个文件使用 UTF-8 编码，时间采用 24 小时制 `HH:MM`，课程须按时间顺序排列且不能重叠。缺少文件或格式错误时会提示文件错误并停止启动，不会回退到内置课表。常规课表省略某个星期或将其设为 `[]` 表示该星期无课。

## 运行

```powershell
python -m pip install -r requirements.txt
python app.py
```

唯一第三方运行依赖是 `PyQt5`（其安装依赖由 pip 处理）；代码不会自动安装或下载依赖。控制台会打印初始化完成状态。桌面模式不出现在 Alt+Tab 中，启动后按 Win+D 查看桌面右侧。如看不到，可执行 `python app.py --windowed --no-save` 检查普通窗口；该模式可以用 Alt+Tab 切换。

不显示控制台：

```powershell
pythonw app.py
```

程序默认显示在主屏右侧：深黑色半透明背景、白色文字，顶部为 `星期X  MM/DD`，下面只有时间和当日课程两列。自动使用电脑本地日期，跨天及休眠唤醒后更新。无课日显示“今天没有课程”，周末也可通过特例安排课程。

- 拖动面板移动；拖动任意边缘或角落调整宽高，右下角有缩放标记。
- 点击右上角锁图标：锁定后不能拖动或缩放；再次点击解锁。
- 时间与课程使用大号粗体白字，适合电子白板；窗口缩放时文字重新绘制，空间不足时自动适配列宽。拖动缩放合并为约 60 次/秒的几何更新，移动时不反复调整桌面层级。
- 高亮为标准圆角矩形，左侧带粗色条。当前课程使用深红底色和红底“正在上课”标签，下一节采用略偏蓝的蓝灰底色和“即将开始”标签。没有 Logo、斜线装饰或流动动画。末课结束及无课日取消标记，预览其他日期不会套用今天的时间。
- 右键面板或系统托盘图标：锁定、预览其他星期、恢复默认位置和大小、退出。预览模式会标注“课表预览”，选择“自动显示今天”返回当天。
- 当前源码的位置、大小和锁定状态保存于程序目录的 `user-data/settings.json`，日志位于 `user-data/app.log`，复制整个程序文件夹即可一起迁移。无需写入 Program Files 或 AppData，程序目录需可写。保留的 V8 成品仍使用其原有 `%LOCALAPPDATA%\DailyDesktopTimetable` 路径。
- 同一用户正常启动只运行一份。程序使用 Windows Explorer 的桌面宿主作为 owner，同时设置底层窗口属性，不占任务栏；普通应用窗口可以覆盖它。透明窗口保留 Qt 的顶层绘制方式，避免直接改成桌面子窗口后不可见。

## DPI 与手动缩放

进程在创建窗口前启用 **Per-Monitor V2 DPI awareness**，Qt 使用当前显示器的原生像素密度绘制文字、线条、锁图标。窗口变化时重新绘制，界面没有先渲染成小图片再放大的步骤。150% / 300% 不会通过 Windows 位图放大界面。

默认宽高和保存的宽高按显示器可用高度计算，位置按剩余可用空间的比例计算。因而 2560×1600 / 150% 与 3860×2160 / 300% 上整体占屏幕的比例接近；两块屏幕宽高比不同，横向占比不会完全相同。拖动边缘可以自由调整宽高，字号随可容纳空间调整。系统缩放、显示器变化后会重新计算，不固定为 96 DPI，也不硬编码 1.5 或 3 倍。

Windows 的 exe“兼容性 → 更改高 DPI 设置”保持默认；若人为强制“系统”或“系统（增强）”缩放，系统会接管缩放，可能使文字模糊。

## 单文件 EXE

保留的成品为 `dist\DesktopTimetable-v8.exe`（Windows x64），支持外置课表与日期特例。复制时同时携带 `dist\timetable.json` 和 `dist\exceptions.json`，三个文件放在同一目录。V8 不包含后续新增的编辑器和时间测试窗口；查看当前 Python 源码界面使用 `python app.py --windowed --no-save`。WinUI 编辑器源码在 `winui-editor/`，已接入当前 Python 主程序；完整应用尚未统一迁移到 C#。

当前源码的编辑器保存后会生成 `template.json`，迁移源码数据时一并携带。不需要为 V8 安装 Python / PyQt5，也不需要携带源码或 PDF。EXE 仅包含程序与运行库，不包含课表数据。

单文件程序启动时会自动把内部运行库解压到系统临时目录，这不是联网下载或安装依赖。首次启动速度受电脑磁盘和杀毒扫描影响。位置、大小及锁定状态仍保存到当前用户的配置目录。

## 重新打包

在此目录执行：

```powershell
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --onefile --windowed --name DesktopTimetable-v9 --distpath dist/editor-v9 --workpath build/editor-v9 --manifest app.manifest app.py
Copy-Item timetable.json, exceptions.json dist/editor-v9/
# 若源码目录已有 template.json，也复制到 dist/editor-v9/。
```

以上命令仅打包 Python 主程序，不包含独立 WinUI 编辑器，暂不构成新版完整分发包；完整便携发布流程待应用统一到 C# 后确定。保留 `--manifest app.manifest`，让打包后的进程从启动起即具备正确的 DPI awareness。不要将 JSON 通过 `--add-data` 内嵌到 EXE。建议使用 64 位 Python 在 Windows 上打包。根目录与打包目录中的 JSON 是各自独立的文件，编辑器保存到当前运行程序所在目录。
