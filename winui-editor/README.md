# WinUI 3 课表编辑器

原生 C# / XAML，使用 Windows App SDK。主课表、例外日期、共享时间模板、独立课程时间、覆盖确认和未保存关闭提醒均在此窗口实现。Windows 11 使用 Mica 背景，控件与颜色跟随系统主题；Windows 10 使用普通背景。新版主程序 `winui-app/` 直接编入本目录源码，在同一个进程中打开编辑器；本项目继续作为独立调试入口和 Python 旧版的编辑器保留。

课表使用所有可见日期共享的时间轴：相同时间横向对齐，课程块按各自开始、结束时间定位。主课表的五个工作日在整个视口内显示，不使用独立列滚动；午休等无课长空档被压缩，课程块高度不代表精确时长。窗口缩放时统一适配时间轴。例外日期也共享时间轴，日期过多时仅横向滚动。

共享模板默认在课表左侧展开为独立纵列，点击模板标题旁的箭头可收起为左侧竖向入口，再点击即可向右展开。两个选项卡共享展开状态。应用操作合并为“应用范围”下拉框和“应用模板”按钮；主课表可选择所有工作日或指定星期，例外页只选已有日期。模板列表可单独滚动，不影响课表的时间位置。

保存按钮与选项卡同排，课表上方不再显示大标题和说明区。课表控件在 XAML 测量和排列阶段定位，首次显示、切换选项卡和窗口缩放均使用同一布局流程；课程卡片统一使用两行排版，时间在左上，课程名称在下方。

课程卡片使用单个淡色表面，仅显示时间和课程实际名称；点击课程名称或卡片空白区域都能打开课程菜单，自定义名称在弹窗输入。课程文字使用较大字号，时间轴旁显示“点击卡片修改”的提示。右侧红色垃圾桶默认隐藏，鼠标悬停或键盘聚焦时显示并贯穿卡片高度。添加课程和时间段使用轻量文字按钮。

例外日期列之间使用额外留白和竖向分割线。主课表和例外课表都根据实际课程数量与最小可读卡片高度计算内容高度，只有内容超过视口时才滚动；使用右上、右下的步进箭头或可拖动滚动条上下查看，日期过多时继续使用横向滚动。

开发电脑需要 .NET 8 SDK；这是源码开发要求。新版主程序以自包含便携文件夹发布到 `release/`，共用一套运行库，详见根目录 README.md。此独立编辑器的启动脚本用于开发查看。

在项目根目录手动查看：

```powershell
./winui-editor/run-editor.ps1
```

或：

```powershell
dotnet run --project winui-editor/Timetable.Editor.csproj -- --data-dir "课表 JSON 所在目录"
```

首次开发运行会从 NuGet 下载 SDK 依赖。程序只读取指定目录的 `timetable.json`、`exceptions.json` 和可选 `template.json`；保存到同一目录。未指定目录时，开发运行会从工作目录或程序目录向上查找课表。周六、周日原有数据会保留。

Python 桌面课表可启动此编辑器，通过标准输入输出交换保存、关闭和未保存状态；保存后立即重新加载外置课表。直接运行本编辑器也能单独编辑数据。

桌面课表、时间测试和托盘现已迁移到 C# 主程序。Python 旧版位于 `legacy/python/`，V8 成品不包含本编辑器。
