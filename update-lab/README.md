# 更新功能实验室

此目录用于本机测试，`v1.1.0` 是包含更新功能原型的测试版，内部版本为 `1.1.0`，与以前发布的正式版不同

双击 `start.cmd`，会启动本机模拟 GitHub 服务、打开场景选择页面，并启动测试课表。服务只监听 `127.0.0.1:18761`

1. 在网页中选场景
2. 在测试课表或托盘图标上右键，选择“检查更新”
3. 查看本机版本、远程版本和返回状态
4. 选择“有新版”后点击“下载并更新”，应从 `1.1.0` 更新到 `1.1.1` 并自动启动

测试版的数据位于 `v1.1.0/` 内，原项目和正式 `release` 的课表不参与更新

`run-checks.ps1` 会启动另一个本机服务，自动验证各种情况，包括真正启动 WinUI 新版、失败恢复、取消与下载校验。报告在 `results/checks.json`

`stop-lab.ps1` 用于关闭手动启动的模拟服务。先关闭测试课表，再运行 `build-lab.ps1` 可以重新构建内部标记为 `1.1.0` 的程序；已有测试 JSON 会保留

实验结束后，使用 `build-lab.ps1 -UseCurrentSources` 从正式源码重新准备实验。二进制、模拟升级包、临时副本和测试数据都已加入本目录的 `.gitignore`

正式程序默认访问指定 GitHub 仓库。只有通过 `--update-test-url http://127.0.0.1:端口/` 明确启动时，才使用本机模拟服务
